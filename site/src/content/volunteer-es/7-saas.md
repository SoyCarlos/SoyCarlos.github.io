  &bull; Realicé investigación independiente sobre tendencias en las listas musicales de EE. UU. a lo largo del tiempo como parte del Comité de I&P.  
  &bull; Apliqué análisis de sentimiento a las 100 canciones más populares de cada año entre 1965 y 2015 para identificar tendencias a través de las décadas.  
  &bull; Utilicé la API de Spotify y la API de Google Cloud Natural Language para recopilar y analizar características de audio y sentimiento lírico.
